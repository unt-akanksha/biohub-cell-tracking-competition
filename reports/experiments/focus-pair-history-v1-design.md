## Motivation and boundary

The saved full-source flow audit attributes613 missed edges to association with
both endpoints detected and271 to a missing detected endpoint. Among613,
540 fail the fixed physical distance/null comparison,72 lose parent competition,
and1 is topology-blocked despite posterior>0.5. These are exposed development
counts, not new validation, an achievable oracle, or a submission score forecast.
Current pair rankers do not explicitly use preceding-frame source image flow.

Earlier causal-motion inference used its own accepted links and a fitted
velocity-shrinkage prior. This proposal instead uses the *image-predicted*
backward flow at each candidate source, joined from the preceding cached packet.
No GT history, accepted-track history, new detector/image inference, or source-
specific fallback. Constant velocity may be wrong at divisions/deformation;
the cue is optional information for a later trained ranker, never a hard veto.

## Fixed feature contract

Seven extra pair features: history-available indicator, three signed residuals,
and their three squares. Residual = [(source-target)*ZYXscale - source's previous
backward image flow - existing frozen mean] / sqrt(existing frozen variance).
All original real candidates and the null option remain. Null features are
zero; first-transition history features are zero with explicit unavailable mask.
For all later transitions, missing/misaligned history is an error, not a fallback.
Row-order changes are handled only through unique exact original node IDs and
equal coordinates. Feature generation never reads current or previous labels.
No inference or training hyperparameter is selected by this audit.
