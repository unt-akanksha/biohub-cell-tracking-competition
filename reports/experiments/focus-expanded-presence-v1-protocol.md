# Prospective expanded-data presence experiment

Prepared while the additional-fitting detector cache is running, before its
labels/coverage are observed. This is a protocol, not a staged/launched fit.

If the eight new fitting movies have complete verified raw detections and
audited labels, extract the SAME frozen original encoder/head/flow features
and compact summaries as the earlier presence experiment. Replay the original
small neural/flow probe before full feature extraction. Preserve all raw
coordinates, exact known-parent/null labels and original four diagnostic
movies. No diagnostic movie enters fitting, and no source/target is opened.

The first controlled follow-up is the original seven-feature offset-logistic
presence model trained on the combined twelve fitting movies. Keep the same
fixed ridge1, unpenalized intercept, L-BFGS-B settings, original conditional
real-parent ranking, previous two-movie physical calibration and inference
decision rule. Standardize using only the combined fitting examples. Change
data coverage, not parameters or decision thresholds. Do not concatenate the
already exposed diagnostic data into training or silently change its labels.

Before fitting, require exact replay of earlier four-movie fitting summaries,
unchanged diagnostic summary hashes/counts and all additional summary hashes.
Persist the twelve-movie fitted parameters before the one corrected diagnostic
evaluation. Apply the SAME original neural/physical feasibility gate: lower
NLL than both, parent correctness at least2585, absence correctness at least18.
No posthoc relaxation or coefficient sweep. A pass remains only permission
for complete-source tracking evaluation under the original promotion gates.

Failed head/linear/tree checkpoints remain failed. This protocol does not
authorize extending them unchanged. If label coverage or extraction cannot
be verified, stop before fitting and report the actual limitation. Every GPU
stage needs a fresh quota check, sequential ownership and8h reserve; no follow-up
launch is automatic merely because the detector cache finishes.
