<objective>
As a Biohub competitor, I want one read-only command to capture and summarize live competition state so that every work session begins from current, source-audited evidence.

This is the production walking-skeleton slice: authenticated external read, atomic persistent write/read, policy classification, and terminal report. It must work against fixtures by default and against the real Kaggle CLI only when `--live` is explicit.
</objective>

<threat_model>
ASVS level 1; block at high severity. Threats are credential leakage through diagnostics, shell injection through Kaggle refs or paths, executing untrusted notebook source during audit, path escape outside configured workspace roots, and stale/partial snapshots being reported as current. Mitigations: never read Kaggle credential files; use subprocess argument arrays with `shell=False`; redact stderr; validate refs against `owner/slug`; treat notebook files as text only; atomic same-directory replace; store UTC collection timestamps and per-command status; fail or render `unavailable` instead of silently reusing stale values.
</threat_model>
